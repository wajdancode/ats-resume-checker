# 📄 ATS Resume Checker & AI Improver

A web app that analyzes your resume, gives you an ATS (Applicant Tracking System) compatibility score, and provides personalized improvement suggestions — powered by **Google Gemini Flash** and **Streamlit**.

## ✨ Features
- 📤 Upload PDF resumes
- 🤖 AI-powered ATS scoring (0–100)
- 📊 Detailed breakdown: Formatting, Keywords, Completeness
- 💡 Specific actionable suggestions to improve your resume
- 🔑 Keywords found + recommended additions
- 📋 Full analysis report view
- ⚡ Fast — uses Gemini Flash for quick responses
